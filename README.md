# Hangman-Game
The Hangman Game is a simple and interactive graphical word-guessing project developed using Java and Java Swing without using any database. In this game, players guess letters to reveal a hidden word from a local text file within a strict 3-lives limit and a 60-second real-time countdown timer. The project features automated random word selection, background audio effects, dynamic on-screen win or lose status messaging, and custom graphics drawing using paintComponent to illustrate stickman stages on incorrect inputs. It demonstrates core concepts of file handling, GUI event driven programming, and computational data structures like ArrayList and HashSet.
